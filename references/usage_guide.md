# 舆情周报生成使用指南

## 环境准备

### 安装依赖

```bash
pip3 install openpyxl python-docx
```

## 脚本使用

### 基本用法

```bash
python3 scripts/generate_report.py \
  --data-file "/path/to/main_data.xlsx" \
  --official-file "/path/to/official_reports.xlsx" \
  --output "/path/to/output_report.docx" \
  --start-date "2026年01月04日" \
  --end-date "2026年01月12日"
```

### 参数说明

- `--data-file`：主数据文件（必需），包含所有监测数据的 Excel 文件
- `--official-file`：官方媒体报道文件（可选），单独的官方媒体报道链接 Excel
- `--output`：输出文件路径（必需），生成的 Word 文档保存位置
- `--start-date`：开始日期（必需），格式：YYYY年MM月DD日
- `--end-date`：结束日期（必需），格式：YYYY年MM月DD日

## 配置文件

配置文件位于 `scripts/config.json`，可以自定义：

### 权威媒体列表

添加或删除权威媒体名称：

```json
"authoritative_media": [
  "中国证券报",
  "上海证券报",
  ...
]
```

### 转载网站列表

需要排除的转载网站：

```json
"repost_sites": [
  "证券之星",
  "东方财富网",
  ...
]
```

### 竞品工作表列表

指定需要读取的竞品工作表名称（严格按关注名单）：

```json
"competitor_sheets": [
  "汇成基金",
  "基煜基金",
  "腾讯理财通",
  "蚂蚁财富"
]
```

### 合作伙伴工作表列表

指定需要读取的合作伙伴工作表名称（严格按关注名单）：

```json
"partner_sheets": [
  "7分钟理财",
  "翼支付",
  "东方金匠",
  "粤开证券",
  "中航证券"
```

### 银行券商工作表列表

当前版本已清空（bank_broker_sheets: []），所有银行券商数据不纳入关注名单。

## 去重规则

### 智能去重机制

1. **标题去重**：标题完全相同的新闻被视为重复，保留时间更早的版本
2. **摘要去重**：摘要完全相同的新闻被视为重复（仅当摘要长度>20字符时）
3. **引号标准化**：自动将中文引号("")转换为ASCII引号(")以识别相同内容
4. **优先保留有摘要的记录**：当标题相同时：
   - 优先保留Excel中有摘要的数据
   - 如果都没有摘要或都有摘要，保留时间更早的版本

### 去重示例

**示例 1：标题相同**
- 记录A：标题="基金销售新规"，时间="2026-01-19"，摘要无
- 记录B：标题="基金销售新规"，时间="2026-01-18"，摘要="盈米基金表示..."
- 结果：保留记录B（有摘要）

**示例 2：引号差异**
- 记录A：摘要包含"以旧换新"（中文引号）
- 记录B：摘要包含"以旧换新"（ASCII引号）
- 结果：识别为相同，保留时间更早的版本

## 常见问题

### Q: 如何修改权威媒体列表？

A: 编辑 `scripts/config.json` 文件中的 `authoritative_media` 数组。

### Q: 如何更新关注名单？

A: 编辑 `scripts/config.json` 中的 `competitor_sheets` 和 `partner_sheets` 数组，严格按照 `说明：舆情周报重点关注名单.doc` 更新。

### Q: 为什么某些新闻没有被包含？

A: 可能的原因：
- 来源不在权威媒体列表中
- 来源在转载网站列表中
- 标题包含公告关键词
- **竞品/合作伙伴**：标题或摘要中没有明确提到机构名称

### Q: 为什么有的新闻显示了摘要，有的没有？

A: 只有**盈米基金重点信息**显示摘要（且摘要必须包含盈米关键词）。竞品、合作伙伴、行业要闻不显示摘要，只显示原文链接。

### Q: 如何修改输出格式？

A: 编辑 `scripts/generate_report.py` 中的 `create_word_document()` 函数。

## 故障排除

### 错误：ModuleNotFoundError: No module named 'openpyxl'

**解决**：安装依赖库
```bash
pip3 install openpyxl python-docx
```

### 错误：KeyError: 'Worksheet 盈米基金 does not exist'

**解决**：确保 Excel 文件包含所需的工作表：
- 盈米基金（必需）
- 配置文件中指定的竞品/合作伙伴工作表

### 错误：日期显示为数字（如46041）

**解决**：脚本会自动将 Excel 日期数字转换为日期格式（YYYY-MM-DD HH:MM:SS）

### 警告：官方媒体报道文件不存在

**说明**：官方媒体报道文件是可选的，如果没有提供会显示警告但继续执行

### 问题：竞品/合作伙伴新闻数量为0

**可能原因**：
1. Excel 文件中该工作表数据为空
2. 新闻来源不在权威媒体列表中
3. **新闻标题或摘要中没有提到机构名称**（常见问题）

**解决方法**：
- 检查 Excel 文件中该工作表是否有数据
- 检查新闻的标题和摘要是否包含机构名称
- 检查新闻来源是否在权威媒体列表中

### 问题：同一篇新闻出现多次

**说明**：可能是因为标题略有不同（如前缀差异）或摘要中引号格式不同导致去重失败。

**解决方法**：
- 脚本已实现引号标准化，应能自动处理大部分情况
- 如果仍有问题，检查标题和摘要的细微差异
